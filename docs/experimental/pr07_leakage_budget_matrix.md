## What these checks do not prove

- Public schema descriptions, ordinary free text or arbitrary coordinator files can still leak private information. Future adapter curation, process/account separation and threat-model approval remain required; this is not a secure Python sandbox.
- Hashes/seals do not authenticate target ownership, true state, human labels or reviewer independence.
- Matching ceilings does not force equal consumption or make simulation usage real provider measurements. Early failure/UNKNOWN cells stay in denominators.
- Shared-preparation debit is a proposed information-ablation policy. End-to-end graph cost, discovery interactions, model currency/cost and sensitivity comparisons need a separately approved accounting contract.
- Cooperative timeouts do not forcibly terminate external tools. No external delivery adapter is implemented.
- Same corpus/pool does not establish independent targets, valid held-out clusters, discovery efficacy, actual human-confirmed effects or general remediation utility.

## Adversarial regression proof

Tests deliberately inject blind-arm graphs, altered pool/schema/utility sets, private/nested feedback keys, unknown tools, stale/cross-arm state, asymmetric script opportunities, unequal limits/reservations, wrong reset scopes, changed updates, fabricated CONFIRMED rows and denominator edits. Rehashed inconsistent archives are rejected. Functional tests separately show public topology affects priority and completed public tool mentions can change adaptive choice, while mere success words and incomplete responses do not supply a reward.

The full suite also preserves PR-05's positive/negative/UNKNOWN golden controls and actual failed-detector sentinel, PR-06's independent-reference PENDING gates and unchanged legacy scoring. No test label or script response is promoted to an independently validated experimental result.
