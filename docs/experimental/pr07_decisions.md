# PR-07 pre-implementation engineering decisions

2026-11-19. PR-06 #21 confirmed merged at b5f70f49e56390dd110432f7ae0b605fe2dcb6b1, latest fetched main. Final experimental master plan v1.0, original roadmap and merged PR-00–06 govern this bounded phase.

- Four arms share one immutable public pool, one selector implementation/seed and the same ceilings/reset/utility/feedback contracts. Only graph visibility and feedback updates differ. No A5/A6 or empirical comparison is implemented.
- Real PR-04 corpus delivery remains unavailable; actual applicability stays UNKNOWN where appropriate. Planning-compatible public pools are explicitly hypothetical engineering inputs. Only data-only in-process scheduler test doubles may simulate dispatch; they never call tools/models or return oracle verdicts.
- Ordinary response text/tool names are the only proposed adaptive feedback. The selector uses tool mentions, not a success/denial/oracle reward. Private policy/evidence/expected labels and cross-arm state are excluded. Free-text and process-level custody still need review before any real adapter.
- Shared preparation (including public graph projection) is measured once and charged identically to all arms as a matched accounting debit, separately from actual physical preparation time. Selection/reset/dispatch/adaptation overhead is charged per arm; equal ceilings do not imply equal consumption. This proposed information-ablation accounting policy is not an approved operational cost protocol.
- Test-double resource claims are explicitly simulation accounting, never measured provider use. Actual model IDs/costs remain missing/not applicable. Unknown requested usage closes the budget, never silently becomes zero. Local timeouts are cooperative; real adapters need cancellation/containment review.
- Schedules use a seeded shuffled four-arm order with cyclic rotation across blocks. Each arm/block has fresh state and deterministic reset scopes. Failed/missing/unsupported cells remain in accounting; no retries, substitutions or hidden global learning.
- PR-01/05 verdict replay is observer-only. No synthetic response or direct tool call establishes a delivered attack or independently confirmed primary finding. Primary counts/effect sizes remain unavailable pending real delivery, source custody, independent labels and root-cause adjudication.
- Legacy prewritten PolicyEnforcingBrain is customer-service-specific and not a portable/generated fix. Its portable remediation adapter remains unsupported. PR-03 vulnerable/hardened configurations can be prospectively paired with identical opportunities and benign controls, without claiming effectiveness.
- Budgets, feedback rules, sampling/cohort, root-cause/case/target clusters, primary denominator, independent evidence, remediation applicability and inferential protocol still need human decisions. All cohort status remains UNASSIGNED; no approval is invented. No PR-08 is authorized.
